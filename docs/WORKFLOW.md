# 配套工作流

七步组织方法参考1475505/miliastra-beyond-simulator的工作流。本页是此配套包的实施清单，不主张七步方法或模拟器为本项目原创。

1. 明确玩法：目标、操作、成功/失败、重开与不做的内容。保存一页设计说明。
2. 先写用例：启动前输入、成功锁定、超时、失败后输入、重开恢复。示例tests直接执行rules.lua。
3. 先体验原型：可用独立HTML或纸面流程确认布局和节奏；原型不替代Lua或原生验证。
4. 准备有权使用的素材：记录来源、许可和资源ID。此包不捆绑游戏美术和音乐。
5. 实现Lua：保持规则与UI分离，在project.json登记模块；为自己的原生模板配置ID，再运行build。
6. 执行测试：本地规则测试和生成物check；如使用外部模拟器，另记录版本、画布、输入、截图及未覆盖能力。
7. 官方编辑器验证：核对真实模板/根控件/脚本绑定，在目标编辑器7.1+及所需设备上验证完整一局。失败则保留证据回到对应步骤；模拟器通过不算原生通过。

每次交付记录：源文件与生成物SHA256、依赖版本、实际执行命令、已通过层级、原生待测项。源码变更后不要直接分发过期dist/main.lua。

上游方法与能力说明：https://github.com/1475505/miliastra-beyond-simulator
