# 原生接入与证据

本包不生成或修改GIL/GIA。使用者需有可编辑的千星奇域工程和相应UI模板。

1. 在自己的项目中记录容器/图片/文本/鼠标交互控件模板ID，写入src/config.lua。ID获取及模板建立方式以官方编辑器当前文档为准。
2. 检查src/ui.lua使用的图片资源ID，替换为项目中实际可用且有权使用的资源。
3. build后使用官方编辑器的脚本工作流添加单入口Lua，并将脚本根绑定至预期根控件。具体入口与生命周期以当前官方文档为准。
4. 确认OnInit/OnStart/OnUpdate被调用，完成启动、成功、超时、重开，检查多分辨率和目标设备输入。
5. 记录编辑器具体版本、设备、测试者、输入步骤、结果。未跑原生时保留nativeEditorVerified:false。

源码包的模板ID默认0以防误用其他项目的GUID。UI及手柄适配示例尚未作为这个独立发布包完成原生验收。
